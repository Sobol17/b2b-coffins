# Ангел: B2B-портал и CRM

Контрагент оформляет заявку из каталога, мастерская ведёт её через производство,
доставку и оплату. В том же приложении работают склад, выплаты и отчёты.
Основная разработка завершена, дальше исправления и улучшения.

- [AGENTS.md](AGENTS.md): инструкции для работы с репозиторием.
- [Локальный запуск и проверки](docs/agent-workflow.md).
- [Развёртывание](docs/deploy.md): Docker и Caddy.
