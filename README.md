# Ангел: B2B-портал и CRM

Контрагент оформляет заявку из каталога, мастерская ведёт её через производство,
доставку и оплату. В том же приложении работают склад, выплаты и отчёты.

- [tech.md](tech.md): контракты, архитектура, роли и дорожная карта.
- [AGENTS.md](AGENTS.md): инструкции для работы с репозиторием.
- [Рабочий процесс](docs/agent-workflow.md): окружение, запуск и полный гейт.
- [PLANS.md](PLANS.md): планирование и продолжение многошаговых задач.
- [Инструкции по ролям](docs/guides/README.md) и [портал](docs/portal-guide.md).
- [Развёртывание](docs/deploy.md): Docker и Caddy, ручной деплой.

Стек: SvelteKit 2, Svelte 5, TypeScript strict, Drizzle и SQLite, shadcn-svelte.
Нужны Node.js ≥22 и pnpm 10.11.0.

Установка зависимостей: `pnpm install --frozen-lockfile`. Настрой экспортированное
окружение по рабочему процессу, выполни `pnpm db:migrate`, `pnpm seed`,
затем `pnpm dev --port 5173 --strictPort`.

Перед мёрджем выполняется полный локальный гейт `tech.md` §11.1.
Workflow CI запускается вручную. Автоматического деплоя нет.
