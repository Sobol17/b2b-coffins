# UI-примитивы

Источник пропсов и поведения: корневой `tech.md` §9, §15, §18, §20.16.

- Единственная база shadcn-svelte. Добавление: `pnpm ui:add <component>`.
  Сначала используй существующий примитив; нехватка пропса это CONTRACT GAP.
- Токены в `src/app.css`. Не добавляй произвольные цвета и вторую UI-библиотеку.
- Бочка `index.ts` остаётся tree-shakeable, `package.json` содержит
  `sideEffects: false`. Без побочных эффектов верхнего уровня и блоков `<style>`.
- Тяжёлую часть контрола за триггером загружай через `LazyComponent`, как
  существующие календарь и Combobox. Не ослабляй strict под сгенерированный код.
- Необязательные пропсы пробрасывай через `definedProps`, без `undefined`.
  Вычисляемое состояние через `$derived`, `$effect` только для внешних эффектов.
- Держи доступность клавиатуры, подписи, фокус и тач-цели от 44 px.
  Поля требуют конкретного placeholder, общие тексты в `lib/utils/placeholders.ts`.
- Изменение общего примитива проверяй в kitchen-sink и на использующем его экране,
  включая телефон. Компонент не фильтрует данные вместо серверной проверки прав.
