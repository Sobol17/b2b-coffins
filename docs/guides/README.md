## Общее для всех ролей мастерской

### Первый вход

1. Откройте адрес системы и введите почту и временный пароль из письма.
2. Система попросит задать свой пароль: не короче 12 символов, со строчной и заглавной буквой и цифрой. Пока пароль не сменён, ни один раздел не откроется.
3. После смены пароля откроется главная страница с плитками ваших разделов.

Если пароль забыт, нажмите «Забыли пароль?» на странице входа: ссылка для сброса придёт на почту. После пяти неверных попыток подряд вход блокируется на 15 минут. Учётную запись заводит и отключает руководитель.

### Установка на телефон

На Android нажмите кнопку «Установить приложение». На iPhone откройте систему в Safari, нажмите «Поделиться», затем «На экран Домой». Значок появится на домашнем экране, приложение откроется без адресной строки.

Без интернета приложение не работает: данные хранятся на сервере.

### Уведомления

Колокольчик в шапке показывает число непрочитанных событий и десять последних. Строка ведёт на экран, где событие можно обработать. Когда список открыт, показанные события считаются прочитанными.

Чтобы события приходили пушем, нажмите «Включить» в полосе «Включите уведомления, чтобы узнавать о заявках сразу». Включать нужно на каждом устройстве отдельно. На iPhone пуш приходит только установленному приложению.

Раздел «Уведомления» внизу бокового меню показывает ленту событий и переключатели: снимите флажок у события, о котором пуш не нужен, и нажмите «Сохранить настройки». Лента в колокольчике приходит всегда.

Писем о событиях система не присылает. На почту приходят только временный пароль и ссылка для сброса пароля.

### Статусы заявки

Заявка идёт только вперёд: «Заявка», «В работе», «Готов к выдаче», «Доставлен», «Ожидает оплаты», «Оплачено». До приёма в работу заявку можно отменить или отклонить. Вернуть заявку на шаг назад нельзя. Брак, переделку и отказ при доставке система не учитывает: такие случаи решает администратор по телефону.
