Задача владельца: перенести рабочие инструкции на Codex, заменить `CLAUDE.md`
обычным `AGENTS.md`, сохранить ограничения проекта и проверить команды.

Первоначальный этап описан ниже. Последующее решение владельца отменяет
порог покрытия и сохранение временных каталогов; см. уточнение в конце.

## Границы

- База работы: `6c30325`, ветка `feat/shop-stations`, ядро v2.1.
- Рабочая ветка: `codex/agent-harness`. C19 остаётся отдельной работой.

## Критерии приёмки

1. `AGENTS.md` является обычным файлом и работает без `CLAUDE.md`.
2. Правила проекта доступны без установки стороннего набора skills.
3. Есть инструкции старта, планирования, продолжения работы, ревью и проверки.
4. Исторические планы доступны, рабочие ссылки не ведут в удалённые файлы.
5. `pnpm test:unit` проверяет порог 90% строк `src/lib/domain/**`.
6. Проверки не подменяются утверждением о готовности; ограничения записаны.
